🎵 Setup Guide

Spotify Lyrics Display braucht eine kostenlose, selbst angelegte Spotify Developer App, damit die App direkt auf diesem Gerät auf dein "currently playing" zugreifen darf. Das dauert ca. 3 Minuten und muss nur einmal gemacht werden.

🤖 Diese App wurde mit Unterstützung von KI (Claude) entwickelt – Konzept, Design und Tests stammen von Sean Corcoran, ein Großteil des Codes wurde mit KI-Hilfe geschrieben. Quelloffen und einsehbar auf GitHub.

1

Spotify Developer Dashboard öffnen

Gehe auf einem beliebigen Gerät zu developer.spotify.com/dashboard und melde dich mit deinem normalen Spotify-Account an.

2

Neue App erstellen

Klicke auf „Create app" und fülle aus:

  • App name: Lyrics Display (beliebig)
  • App description: Lyrics display for my own account
  • Redirect URI: …
  • APIs used: Web API

Bestätige die Terms und klicke „Save".

3

Client ID kopieren

In der App-Übersicht findest du unter „Settings" die Client ID. Ein Client Secret wird nicht gebraucht – die App meldet sich per PKCE an, ganz ohne geheimen Schlüssel auf dem Gerät.

FAQ

Brauche ich Spotify Premium?

Nein. Die App liest nur „currently playing" – das funktioniert mit jedem Account.

Werden meine Daten irgendwo gespeichert?

Nein, nirgendwo extern. Spotify-Tokens und Client ID liegen verschlüsselt nur auf diesem Gerät. Lyrics werden lokal in den App-Daten gespeichert – lösch- und einsehbar über ⚙. Es gibt keinen Server und keine Übertragung außer an Spotify und LRCLib.

Was ist LRCLib?

lrclib.net ist eine freie, öffentliche Lyrics-Datenbank mit synchronisierten LRC-Lyrics. Kein Account nötig, keine API-Keys.

Warum meine eigene Spotify-App statt einer eingebauten?

Spotify beschränkt neu angelegte Apps ohne Review auf 25 freigeschaltete Accounts. Mit einer eigenen, kostenlosen Developer-App pro Nutzer entfällt dieses Limit – und niemand außer dir hat Zugriff auf deine Zugangsdaten.
